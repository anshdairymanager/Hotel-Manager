Install as Mobile App

PWA (Home Screen) & Android APK Ready

Option 1: Install via Browser (Recommended — Free)

  1. Click Download App HTML below to save index.html.
  2. Drop that file onto app.netlify.com/drop to get your private link.
  3. Open the link in Chrome/Brave on your phone, tap ⋮ (3 dots) → Install App / Add to Home Screen.

Option 2: Create Direct Android .APK File

  1. Download index.html using the button below.
  2. Open WebIntoApp.com (or AppsGeyser) → select HTML Files.
  3. Upload index.html, set your Hotel Name & icon, and download your personal .apk.
